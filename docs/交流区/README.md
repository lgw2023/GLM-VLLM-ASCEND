# 三人文档交流区

这里是 liguowei、qinyingqi、yangyinyue 共用的唯一交流入口。每个人工作文件夹里的 `交流区` 都指向本目录，不保存副本。

## 目录

- `需求/`：任务、问题和验收条件。
- `交接/`：代码 commit、验证结果和待接续事项。
- `决策/`：三人已确认、后续都要遵守的共同决定。

一条事项使用一个 Markdown 文件，文件名采用：

```text
YYYYMMDD-HHMM-发送人-to-接收人-简短主题.md
```

接收人为全体时写 `all`。同一事项的回复和状态更新写回原文件，不重复新建总结。

## 内容格式

```markdown
# 标题

- 类型：需求 / 交接 / 决策
- 发起人：
- 接收人：
- 创建时间：YYYY-MM-DD HH:MM
- 状态：待处理 / 处理中 / 待确认 / 已完成
- 涉及仓库：vllm / vllm-ascend / 文档
- 分支或 commit：

## 内容

说明背景、目标、边界和验收条件。

## 回复与结果

由接收人补充处理结论、验证证据和后续事项。
```

## 协作边界

- 个人方案、脚本、实验记录和待合入成果放在项目根目录各自的 `<姓名>/` 中。
- 公共代码只走同一个 `main` 主分支；传递代码时记录涉及文件和 commit ID，不在交流区复制源码。
- 需要三人共同遵守的结论放入 `决策/`，普通讨论不沉淀为多份文档。
- 不在交流区写密码、私钥、Token 或其他认证信息。
